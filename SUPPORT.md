# VCAMSX support

Download the current official app from [Releases](https://github.com/Hushcedar/Vcamsx/releases/latest), then check the [setup guide](docs/SETUP.md).

## Report a problem

[Open a GitHub issue](https://github.com/Hushcedar/Vcamsx/issues/new/choose) with:

- VCAMSX version, phone model and Android version.
- Selected engine and target app name/version.
- Steps that reproduce the problem.
- Expected result and actual result.
- Relevant screenshots or diagnostic output with private information removed.

Public issues are suitable for download errors, setup questions and technical bugs. Do not include license keys, payment receipts, card details, passwords or private media. Describe payment or activation errors without posting those details.

## Repository scope

This repository distributes official releases and documentation. Android source-code contributions and signing-key requests are outside its scope.
