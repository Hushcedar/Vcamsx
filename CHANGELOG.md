# VCAMSX release notes

## 2.1.3 — 7 November 2026

- Cleaner home layout with compact **Target apps** selection and diagnostic tools in the overflow menu.
- Separate camera and audio sections, with a full-width **Add Audio** action.
- Restored **Open The Real Scene** control and a decoding toggle that shows the selected software or hardware mode.
- Working MP3 playback controls and local audio monitoring tied to microphone activity.
- Clean UUID license-key display and copying.
- Consistent **VCAMSX** branding and fixed gateway pricing: **₦21,000 NGN** through Flutterwave or **$15.00 USD** through NOWPayments.

This is the normal app release. The experimental UI redesigns and proposed new container engine are not included.

### Updating

Install the APK over your existing official VCAMSX installation. It uses the same application package and signing certificate as version 2.1.0, with version code increased from 9 to 12.
